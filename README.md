#  Game Design Study (MANA)
> **교내 게임 개발 동아리 'MANA' 기획 파트 온라인 학습 및 인사이트 공유**

##  개요
- **활동 기간:** 2025.12.20 ~ 2026.01.29
- **목표:** 게임 기획 기초 역량 강화

##  주차별 학습 내역

### 1주차: 게임 분석 및 가치 발굴 (Good Game Analysis)
- **주제:** 인생 게임과 좋은 게임의 정의 및 선정 사유 분석
- **내용:** 특정 게임이 유저에게 주는 핵심 재미 요소(Core Pleasure)를 언어화하고, 게임의 완성도를 결정짓는 기획적 요소에 대한 리포트 작성.

### 2주차: 시스템 구조화 (Feature List Writing)
- **주제:** 게임 분석을 통한 피쳐리스트(Feature List) 작성
- **내용:** 기능이 단순한 게임을 선정하여 게임의 구성 요소를 세분화하여 기획의 논리적 구조 학습.

### 3주차: 아이디어 제안 및 커뮤니케이션 (Pitching)
- **주제:** 기존 게임을 참고한 신규 아이디어 제안서 작성
- **내용:** 기존 게임 분석을 기반으로 제안서 작성 및 발표 연습을 통해 기획 의도를 효과적으로 전달하는 연습 수행.

### 4주차: 프로토타이핑 (Unity 2D Build)
- **주제:** 유니티 프리미티브(기본 도형)를 활용한 2D 게임 제작
- **내용:** 리소스가 배제된 환경에서 게임의 '핵심 메커니즘'만으로 재미를 검증하는 최소 단위 프로토타이핑 수행.
- **빌드:** https://drive.google.com/drive/folders/1mwCR2PizGUK6vtkLifwTq1eFZYGSJW-0

## 💡 성과
- 정기 리뷰를 통해 기획안을 다듬고 팀원 피드백을 반영하는 협업 경험
- 아이디어를 피쳐리스트와 제안서로 정리하는 문서화 경험
- Unity 기본 물리·로직을 직접 다루며 구현 가능한 기획 감각 습득
